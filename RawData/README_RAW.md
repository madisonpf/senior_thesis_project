## Raw Data

This is where data from Infoview will be stored and any data files that result as an analysis product. If you need to make changes to the raw data, you should either comment on changes with the DATE of changes or copy the original files and place in the UPDATED folder, or make the change programatically in *DataCurationCode*.

These files will typically *not* be made public upon submission/publication. 

##USAGE 
The two folders are below:
*RAW DATA* --> Raw data files from Infoview taken directly from database. Please do not move or change any of these files!
*UPDATED* --> If an update to the data file is needed, please download the data file from *Raw Data* and re-upload the change with date and initials of the person who changed the files.
