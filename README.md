# Pathways and Predictors of Senior Thesis Projects at UCSC


## Project description

This is a repository for code and drafts for the project identifying the pathways to senior thesis completion as well as examining demographic disparities in senior thesis participation. This work will add to the existing literature on the importance of high-impact research practices for closing the knowledge gap in higher education and serve as a call to action to improve funding for pathways to science in higher education. 


## Usage

Folders below and brief explanations: 

- DataCurationCode --> pre-preprocessing code for data merging and manipulation *(private)*
- AnalysisCode --> code for processing Infoview scrambled ID data, analysis, and figure curation *(public)*
- TablesFigures --> used for storing tables/figures in finalized condition for publication *(public)*
