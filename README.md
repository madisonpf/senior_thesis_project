# Identifying Demographic Disparities in EEB Senior Thesis


## Project description

This is a repository for data, code, and drafts for the project identifying disparities in senior thesis completion as well as examining potential drivers of disparities in senior thesis participation. This work will add to the existing literature on the importance of high-impact research practices for closing the knowledge gap in higher education and serve as a call to action to improve funding for pathways to science in higher ed. 


## Usage

Folders below and brief explanations: 

- RawData --> used exclusively for daw Infoview files *(private)*
- DataCurationCode --> pre-preprocessing code for data merging and manipulation *(private)*
- SharedData --> data for OSF/Dryad uploading during publication process *(public)*
- AnalysisCode --> code for processing Infoview scrambled ID data, analysis, and figure curation *(public)*
- TablesFigures --> used for storing tables/figures in finalized condition for publication *(public)*
- References --> list of references (copy provided in MS) *(private)*
- Drafts --> drafts of MS as they develop. Please upload changes to draft in the following format: DATE_ProjectName_editor initials (21Jan25_SeniorThesisMS_mp)*(private)*
