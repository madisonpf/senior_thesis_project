# Tables and Figures

This stores all final figures used for the main manuscript text, including conceptual figures and aggregated final figure versions. Naming of the figures here are associated with their positioning in the manuscript. 

Structure: 
Main_MS_Table/: Contains the .csv version of Table 1 in the manuscript.

Final_Figures/: Includes publication-ready figures, complete with lettering and final formatting. These files match the exact figures shown in the manuscript.

Raw_Exports/: Contains the raw figure components used to assemble each multi-panel figure. Each figure has its own subfolder with exported .png files for panels.

Notes: 
- File names follow the numbering and structure of the manuscript.
- Final figures are saved at high resolution for publication (≥600 dpi).
- Raw panels are preserved so figures can be recreated if needed.
